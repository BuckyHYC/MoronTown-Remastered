# 美术规格（对标 640.gif）

## 1. 目标拆解

GIF 的观感由五件事撑起来，缺一不可：

1. **高模车 + 完整内饰**：真实比例、门缝凹槽、轮辋/卡钳、灯组透镜、牌照。
2. **湿路反射**：路面像镜子，标线、车灯、招牌都在反光里。
3. **城市层次**：近处橱窗/雨棚/招牌 → 中层塔楼窗格 → 远景天际线 + 雾。
4. **电影后处理**：泛光、暗角、颗粒、色散、运动模糊，统一色温。
5. **信息密度克制的 HUD**：四角布局、等宽数字、细遥测条。

本项目不追求「全霓虹夜」，而是让白天与夜间各自成立：白天靠天空、材质对比与长阴影；夜间靠自发光、光池与反射。

## 4. HUD 栅格

```
┌ 名次 4/8                圈数 01/03                    小地图 220² ┐
│                         计时 00:09.655                            │
│                                                                   │
│                                            速度环（弧形刻度 + 数字）│
│                                            挡位 / 转速条           │
└ 金币 · 撞击 · 视角 · 时段        遥测细条             暂停/提示   ┘
```

- 字体：Inter / system-ui；数字用等宽 `font-variant-numeric: tabular-nums`。
- 面板：`rgba(7,13,21,.6)` + 1px 描边 + `backdrop-filter: blur(18px)`。
- 动画 0.12–0.18s；`prefers-reduced-motion` 下关闭。

## 6. 禁止

- 不允许「均匀白窗点」式建筑（必须有层线、裙房、屋顶设备）。
- 不允许纯色路面（必须有颗粒、标线、接缝）。
- 不允许无接地感的车（必须有接触阴影 + 太阳投影）。
- 不允许 UI 元素遮挡驾驶视野中心。
