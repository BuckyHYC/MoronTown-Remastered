# 旧版功能第一性原理蒸馏

> 输入：旧项目（MoronTown / FenzaRoad）v1 + v2 的行为、数值与 60 条 e2e。
> 输出：本项目的移植契约。**旧文件一行未复制**，数值全部重新登记为 `src/core/Config.ts`。

## 1. 三条体验支柱

1. **速度感** = 加速度曲线 × 相机动态（FOV/抖屏/后坐） × 声音分层 × 后处理（运动模糊/泛光）。
2. **空间掌控感** = 可读路网 × 一致的碰撞反馈 × 导航信息（小地图 / 检查点 / 记分）。
3. **目标与成长** = 短循环（一圈 / 一次任务） × 长循环（金币 → 车 → 成就 → 每日）。

旧版所有功能都能落到这三条上；落不上的（分享、调试面板）是表现层附属。

## 2. 六个不可再分的系统

```
输入 → S1 车辆动力学 → S2 世界与碰撞
                        ├─ S3 交通 / 行人（活的街道）
                        ├─ S4 竞速 / AI（目标）
                        └─ S6 表现层（渲染 / 相机 / 音频 / HUD）← S5 元系统（经济 / 车库 / 成就 / 存档 / 联机）
```

新项目按此切模块：`gameplay/Dynamics`、`world/*`、`gameplay/(Traffic|Race)`、`meta/*`、`render|ui|audio`。

### 3.7 界面

HUD：速度、金币、击杀、圈数/名次/用时/最佳圈速、小地图（168²）、暂停；移动端右下角部件移到右上。

### 3.8 音频 / 特效 / 联机

- 引擎：3 谐波 + 噪声 + waveshaper + 动态低通（基频 58→290Hz）；胎噪/风噪/换挡/碰撞/雨/UI；master → Compressor。
- BGM：程序化和弦（CALM / RACE），增益 0.16 / 0.2。
- 特效：胎痕（实例化 420 段）、胎烟、火花、雨幕、体积光锥、光池、速度模糊。
- 联机：WS `/multiplayer`，8 人房，`createRoom/joinRoom/leaveRoom/startGame/listRooms/state`，15Hz 上报，远端 `1-exp(-12dt)` 插值，重连 `min(3000n, 10000)`。
